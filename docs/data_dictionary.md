# Data dictionary

> **DEMONSTRATION / SYNTHETIC DATA.** All fields describe simulated data generated by
> this repository. No field contains or represents patient information.

**Status:** Draft (Phase 1). Finalized in Phase 2 together with the generator and the
validation rules.

## `demo_expression.csv` (planned)

| Field | Type | Description |
|---|---|---|
| `sample_id` | string, unique | Synthetic sample identifier (index column) |
| `SYN_G0001` ... `SYN_Gnnnn` | float, may be missing | Simulated continuous log2-like expression value. Identifiers do not correspond to real genes. |

## `demo_metadata.csv` (planned)

| Field | Type | Allowed values | Description |
|---|---|---|---|
| `sample_id` | string, unique | matches expression rows | Synthetic sample identifier |
| `group` | categorical | `Group_A`, `Group_B` | Arbitrary synthetic group label. **Not** a diagnosis or clinical category. |
| `batch` | categorical, optional | `Batch_1`, `Batch_2`, ... | Simulated technical batch |

## `demo_ground_truth.csv` (planned)

| Field | Type | Description |
|---|---|---|
| `gene_id` | string | Synthetic gene identifier |
| `is_signal` | bool | Whether a group difference was planted |
| `direction` | categorical | `up`, `down`, or `none` (in `Group_B` relative to `Group_A`) |
| `true_shift` | float | Planted mean shift (0 for non-signal genes) |
