# data/raw/

Place **user-supplied** input files here for local analysis. Everything in this
directory except this README and `.gitkeep` is ignored by Git.

Rules:

- **Never** place real patient data, protected health information, controlled-access
  data, or credentials here, and never commit them.
- Only small, openly licensed public data may ever be added to the repository, and
  only with its source, license, and permission documented and approved first.
- The project ships no external datasets. The demo workflow uses the synthetic files
  in `data/synthetic/`.
