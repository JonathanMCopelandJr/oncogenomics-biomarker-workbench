# data/synthetic/

**DEMONSTRATION / SYNTHETIC DATA — RESEARCH AND EDUCATION ONLY — NOT FOR CLINICAL USE.**

> **DEMONSTRATION / SYNTHETIC DATA.** Every value in this directory is simulated by
> this repository's generator (`onco_workbench.data.synthetic`). It is **not** patient
> data, contains no real, restricted, or private data, and does not describe real
> genes, real samples, or real biology. Group labels are arbitrary and are not diagnoses.

## Files

| File | Size | Contents |
|---|---|---|
| `demo_expression.csv` | ~249 KB | 80 samples (rows) x 500 synthetic genes (columns), continuous log2-like values, 3 decimals, blank = missing |
| `demo_metadata.csv` | ~2 KB | `sample_id`, `group` (`Group_A` / `Group_B`), `batch` (`Batch_1` / `Batch_2`) |
| `demo_ground_truth.csv` | ~14 KB | Which synthetic genes had a group difference planted, and its size. Used to test that a workflow recovers them. |
| `demo_manifest.json` | ~2 KB | Seed, generator parameters, data license, and SHA-256 checksum of each CSV |

Each CSV begins with two `#` comment lines carrying the DEMONSTRATION / SYNTHETIC label.
Read them with `pandas.read_csv(path, comment="#")` or with the loaders in
`onco_workbench.data.io`. Field definitions are in
[`docs/data_dictionary.md`](../../docs/data_dictionary.md).

## Provenance

- Generated by `obw generate-data` using `config/default.yaml` (seed `42`).
- Model: per-gene baseline + per-batch offset + Gaussian noise + a planted shift for
  40 "signal" genes (20 up, 20 down in `Group_B`), then 0.5% of values set to missing.
  Details: [`docs/methodology.md`](../../docs/methodology.md).
- No external data sources were used.

## Regenerating

```bash
obw generate-data            # rewrites the four files in this directory
obw validate                 # checks them
```

Regeneration with the same seed and configuration is **byte-identical**.
`tests/test_demo_data.py` regenerates the files in a temporary directory and compares
SHA-256 checksums with the committed files, so any drift fails the test suite. To write
elsewhere, use `obw generate-data --output-dir <dir>`. To try a different seed without
touching the committed files, use `--seed <n> --output-dir <dir>`.
